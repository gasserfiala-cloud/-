getting started

Your project is a collection of files and folders,
not a configuration file stored inside VS Code. You can open code you already have or create a folder for a new project.When you open a folder, it becomes a workspace. The editor uses it as the context for finding files, searching code, and applying project settings. The integrated terminal lets you run your project's commands alongside the code. If your project uses Git, source control shows the changes you make.You can also open an individual file for a quick edit. Opening the project folder is more useful when you need to work across files or run the application. Learn more about how
